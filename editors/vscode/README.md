# ПотужнийСкрипт для VS Code

Підсвітка синтаксису файлів `*.potuzhno`: звичайний JavaScript (граматика VS Code) плюс мемні слова,
які підсвічуються як ключові слова, типи, константи, класи й методи залежно від того, що вони замінюють.

## Встановлення

```sh
npm install
npm run package
code --install-extension potuzhno-syntax-0.1.0.vsix
```

## Іконка

Файли `.potuzhno` у провіднику отримують зелену іконку «Зе» (`icons/potuzhno.svg`), якщо тема іконок файлу не має власної для цієї мови.

## Оновлення словника

Мемні слова беруться з `src/dictionary/meme-entries.ts`. Після зміни словника:

```sh
npm run generate   # перегенерує syntaxes/potuzhno-keywords.injection.json
npm test           # перевіряє граматику й що згенерований файл свіжий
```

Обмеження: мемне слово у вкладеному шаблонному рядку всередині `${}` може підсвітитися.

## Налаштування для `.potuzhno`

Розширення вимикає для цієї мови підсвітку «схожих символів» (кирилична `а` проти латинської `a`) і перевірку орфографії Code Spell Checker: усі слова тут мемні й кириличні.

## Підказки

Під час набору в `.potuzhno` VS Code пропонує мемні слова зі словника, а праворуч показує, що слово означає в JS (`потужно` → `let`). Список лежить у `completions.json` і генерується разом із граматикою: `npm run generate`.
